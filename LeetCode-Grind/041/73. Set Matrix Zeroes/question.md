# LeetCode 73 - Set Matrix Zeroes

## Question

Given an `m x n` integer matrix `matrix`, if an element is `0`, set its entire row and column to `0`.

You must do it **in-place**.

## Example 1

**Input**
```text
[[1,1,1],
 [1,0,1],
 [1,1,1]]
```

**Output**
```text
[[1,0,1],
 [0,0,0],
 [1,0,1]]
```

## Example 2

**Input**
```text
[[0,1,2,0],
 [3,4,5,2],
 [1,3,1,5]]
```

**Output**
```text
[[0,0,0,0],
 [0,4,5,0],
 [0,3,1,0]]
```
