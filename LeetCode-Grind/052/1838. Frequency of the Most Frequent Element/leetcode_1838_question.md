# LeetCode 1838 — Frequency of the Most Frequent Element

Given an integer array `nums` and an integer `k`, one operation increments any element by `1`.

Return the maximum possible frequency of an element after at most `k` operations.

### Example 1
```text
Input: nums = [1,2,4], k = 5
Output: 3
```

We can make `[1,2,4]` into `[4,4,4]` using `3 + 2 = 5` operations.

### Example 2
```text
Input: nums = [1,4,8,13], k = 5
Output: 2
```

### Example 3
```text
Input: nums = [3,9,6], k = 2
Output: 1
```
