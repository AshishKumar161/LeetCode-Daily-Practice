# LeetCode 204 - Count Primes

## Question

Given an integer `n`, return the number of prime numbers that are strictly less than `n`.

## Example 1

```text
Input: n = 10
Output: 4
```

The primes strictly less than `10` are:

```text
2, 3, 5, 7
```

## Example 2

```text
Input: n = 0
Output: 0
```

## Example 3

```text
Input: n = 1
Output: 0
```

## Constraint

```text
0 <= n <= 5 * 10^6
```
