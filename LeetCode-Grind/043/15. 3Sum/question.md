# LeetCode 15 - 3Sum

## Question

Given an integer array `nums`, return all triplets `[nums[i], nums[j], nums[k]]` such that:

```text
i != j
i != k
j != k
nums[i] + nums[j] + nums[k] == 0
```

The solution set must not contain duplicate triplets.

## Example 1

```text
Input:  nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

## Example 2

```text
Input:  nums = [0,1,1]
Output: []
```

## Example 3

```text
Input:  nums = [0,0,0]
Output: [[0,0,0]]
```
