# LeetCode 485 - Max Consecutive Ones

## Question

Given a binary array `nums`, return the **maximum number of consecutive `1`s** in the array.

---

## Example 1

**Input:**
```text
nums = [1,1,0,1,1,1]
```

**Output:**
```text
3
```

**Explanation:**

The first group contains `2` consecutive ones and the last group contains `3` consecutive ones. Therefore, the maximum is `3`.

---

## Example 2

**Input:**
```text
nums = [1,0,1,1,0,1]
```

**Output:**
```text
2
```

---

## Constraints

* `1 <= nums.length <= 10^5`
* `nums[i]` is either `0` or `1`.
