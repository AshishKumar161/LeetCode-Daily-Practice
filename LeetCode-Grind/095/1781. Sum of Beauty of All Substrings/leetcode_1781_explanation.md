# LeetCode 1781: Sum of Beauty of All Substrings - Detailed Explanation

## 1. Problem Understanding & Core Intuition

* We are given a lowercase English string `s` of length $n \le 500$.
* For every possible contiguous substring of `s`, its **beauty** is defined as:
  $$\text{beauty} = \max(\text{frequency of present characters}) - \min(\text{frequency of present characters})$$
* **Crucial Detail:** Only characters that **actually appear** in the substring ($\text{freq}[k] > 0$) are considered when computing the minimum frequency. Characters with frequency $0$ are ignored.
* Since $n \le 500$, generating every substring using two nested loops (`i` for the start index and `j` for the end index), counting character frequencies using a size-26 array, and accumulating `maxx - minn` directly computes the total beauty sum.

---

## 2. Code Implementation Walkthrough

```cpp
class Solution {
public:
    int beautySum(string s) 
    {   
        int n = s.size() ;
        int ans = 0 ;


        for (int i = 0 ; i < n ; i++)
        {
            string temp = "" ;

            for (int j = i ; j < n ; j++)
            {
                temp += s[j] ;
           

                vector < int > freq (26, 0) ;

                for ( int k = 0 ; k < temp.size() ; k++)
                {
                    freq[temp[k] - 'a']++ ;
                }

                int maxx = 0 ;
                int minn = INT_MAX ;

                for (int k = 0 ; k < 26 ; k++)
                {
                    if (freq[k] > 0)
                    {
                        maxx = max (maxx , freq[k]) ;
                        minn = min (minn , freq[k]) ;
                    }

                }

                ans += (maxx - minn) ;
                }
            }

        return ans ;

    }
};
```

### Detailed Execution Flow:

1. **Substring Generation (`i` and `j` loops):**
   * The outer loop fixes the starting index `i` ($0 \le i < n$) and initializes an empty string `temp = ""`.
   * The inner loop extends the substring one character at a time (`temp += s[j]`) from `j = i` to `n - 1`.
2. **Frequency Counting (`freq` vector):**
   * A vector `freq(26, 0)` maps `'a'` through `'z'` to indices `0` through `25` using `temp[k] - 'a'`.
   * Iterating through `temp` populates the exact count of every character present in the current substring.
3. **Finding Max and Min Frequencies:**
   * Initialize `maxx = 0` and `minn = INT_MAX`.
   * Scan all $26$ buckets. Whenever `freq[k] > 0`, update `maxx` and `minn`.
4. **Accumulating Beauty:**
   * Add `(maxx - minn)` to `ans`. Note that substrings of length $1$ or substrings with identical character counts have `maxx == minn`, naturally contributing $0$.

## 4. Complexity Analysis

* **Time Complexity:** $\mathcal{O}(n^3)$
  * There are $\frac{n(n+1)}{2}$ substrings generated by the nested `i` and `j` loops.
  * For each substring of length $L$, the loop over `temp.size()` runs in $\mathcal{O}(L)$ time, followed by a constant $26$-step scan.
  * Summing across all substrings gives $\sum_{i=0}^{n-1} \sum_{j=i}^{n-1} (j - i + 1) = \frac{n(n+1)(n+2)}{6} = \mathcal{O}(n^3)$ operations. With $n \le 500$, this performs at most $\approx 2.08 \times 10^7$ simple operations, passing comfortably within time limits.
  * *(Note: Moving `vector<int> freq(26, 0)` outside the `j` loop and updating `freq[s[j] - 'a']++` incrementally reduces the runtime to $\mathcal{O}(26 \cdot n^2)$).*
* **Space Complexity:** $\mathcal{O}(n)$
  * The auxiliary string `temp` grows up to length $n$ in the worst case, while the `freq` vector uses constant $\mathcal{O}(26) = \mathcal{O}(1)$ space.

## 5. Edge Cases Handled

1. **Single Character String (`s = "a"`):**
   * $n = 1$; `temp = "a"`, `maxx = 1`, `minn = 1`. Beauty is $0$, returns `0`.
2. **All Identical Characters (`s = "aaaa"`):**
   * Every substring contains only `'a'`, so `maxx == minn` for all substrings. Returns `0`.
3. **All Unique Characters (`s = "abcdef"`):**
   * Every character in every substring appears once (`maxx = 1, minn = 1`). Returns `0`.
