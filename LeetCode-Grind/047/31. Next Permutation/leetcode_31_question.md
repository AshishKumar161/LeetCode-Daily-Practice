# LeetCode 31 - Next Permutation

## Question

Given an array of integers `nums`, find the **next lexicographically greater permutation** of `nums`.

If no greater permutation exists, rearrange the array into the lowest possible order.

The modification must be **in-place** and use **constant extra memory**.

## Examples

```text
Input:  nums = [1,2,3]
Output: [1,3,2]

Input:  nums = [3,2,1]
Output: [1,2,3]

Input:  nums = [1,1,5]
Output: [1,5,1]
```
