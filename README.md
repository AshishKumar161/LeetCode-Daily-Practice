## Problem-Solving Approach

For most problems, I follow a progression like this:

**1. Understand**  
Read the problem carefully, identify constraints, inputs, outputs, and edge cases.

**2. Brute Force**  
Build the simplest correct solution first to understand the problem.

**3. Improve**  
Look for patterns, better data structures, sorting, hashing, two pointers, binary search, recursion, or other applicable techniques.

**4. Optimize**  
Reduce unnecessary work and target the best practical time/space complexity.

**5. Dry Run**  
Manually trace the algorithm on representative examples.

**6. Analyze**  
Record time complexity, space complexity, and important observations.
